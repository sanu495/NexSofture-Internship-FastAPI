Student Management System

Student Management System is a clean and simple web application built to help schools keep every student record in one place – from admission to class allocation and contact details.

Designed with FastAPI, SQLModel and MySQL, it allows admins to create, update and search students in seconds, instead of managing scattered Excel files or paper forms.

This project focuses on clarity: a minimal interface, fast loading pages and form‑based workflows that make daily tasks easy for teachers and office staff.
